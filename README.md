# PWR Industries bug tracker

This is the public bug tracker for PWR Industries Mac apps.

Bug reports come in through the form at **https://www.pwr.industries/bugs**, so you don't need a GitHub account to report one. Reports are reviewed and filed here as issues, one label per app (for example `octet` for Octet TFTP / Octet TFTP Lite).

**Please never include passwords, enable secrets, SNMP communities, keys or full device configs** in a report.

Labels:
- `octet` – Octet TFTP and Octet TFTP Lite
- `veilrunner` – Veilrunner (Mac MUD client)
- `configsmith` – ConfigSmith (hardened IOS-XE baseline configs)
- `bug` – confirmed or reported bug
- `needs-triage` – new, not reviewed yet

Questions or anything else: https://www.pwr.industries/contact.html
